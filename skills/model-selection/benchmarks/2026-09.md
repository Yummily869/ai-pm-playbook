- 几乎所有模型的**中文文字渲染**质量都显著低于英文，常见问题：字形扭曲、笔画缺失、位置偏移

- Stability AI 曾传出经营困难消息，选用 SD 系列时需评估长期维护风险

### Seedance 2.5 参数变化（2026-07-31 发布）

| 参数 | 2.0 | **2.5** | 因此第一次能做什么 |
|------|-----|--------|----------------|
| 单次生成时长 | 15s | **30s，支持多轮延长** | 装下铺垫→推进→转折→收尾的完整叙事 |
| 参考素材上限 | 有限 | **30 图 + 10 视频 + 10 音频** | 多主体群像场景第一次可控 |
| 编辑能力 | 重新生成 | **时间戳定向编辑、绿幕编辑** | 从「不满意重抽」变成「哪段不对改哪段」 |

### MiniMax H3 特性（2026-07 发布）

- 四模态参考输入（图片 + 视频 + 音频 + 文字）
- **绝对秒数时间轴**：可写 `在第 3.5 秒，人物转头`
- 中文口播唇形同步

> ⚠️ **Prompt 语法冲突**：H3 使用绝对秒数；Seedance 2.0 系禁用秒数，只能用镜头序号。
> 两者 prompt 不可直接复用，切换模型时需重写。详见 [`../../../references/`](../../../references/)

**已知能力边界**
- 各模型官方 demo 均经过精选 prompt 和多次重试，实际稳定性显著低于 demo 观感
- 竖屏（9:16）场景下多数模型表现弱于横屏，因训练数据以横屏为主
- 人物手部、快速运动序列仍是普遍崩坏点

**已知能力边界**
- 视觉 token 成本随帧数线性增长，长视频场景需控制关键帧采样率，否则成本失控
- 不同模型对视频帧的 token 计算方式差异极大，**无法跨模型直接比较单价**，需用真实素材实测
- 「识别型」任务（描述画面）和「推理型」任务（判断是否高光）能力差距显著，7B 级模型通常只能胜任前者

**已知能力边界**
- Arena 榜单前两名（CastleFlow、Vocu）**无公开 API**，排名高但不可用
- 各厂商宣称的「X% 用户更偏好我们」盲测数据**均为厂商自测**，不是独立评测
- 长文本（>1000 字）稳定性普遍缺少公开数据，多数模型只测过 200 字以内
- 中文多音字、人名地名读法是国内场景高频问题，需专门准备测试用例

**已知能力边界**

- 结构化输出（JSON）稳定性差异很大，Agent 场景必须单独测试，不能依赖通用能力排名

## 本表的已知盲点

| 盲点 | 影响 |
|------|------|
| 星级为综合判断非实测 | 不能作为最终选型依据 |
| 视觉理解成本无法横向比较 | 需用真实素材实测 token 消耗 |
| 国内模型 SLA 条款不透明 | 公开文档描述模糊，需商务谈判确认 |
| 中文 TTS 缺少近期独立评测 | 现有数据多为厂商自测 |
| 多个模型价格标注「以官网为准」 | 成本维度信息不完整，需自行补齐 |
